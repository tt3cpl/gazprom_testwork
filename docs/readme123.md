# Шаги для запуска:
### Перейти в папку приложения:

```
cd gazprom-app
```

### Установить зависимости:
```
npm install
```
### Запустить dev-сервер:

```
npm run dev
````

### Открыть браузер по адресу, который будет показан в терминале (обычно http://localhost:5173)




#### Технические требования:
• Использовать React

• Библиотека состояний, при необходимости: на ваш выбор

• Библиотека UI компонентов - Consta

• Код должен быть на TypeScript

• Должно работать в Яндекс.Браузере и Edge

• UI должен хорошо выглядеть на разрешениях от 1024 до 1920

• Использовать API https://gorest.co.in/


Функциональные требования:

    Главная страница
    • Поле ввода для access token. Валидация (токен не пустой).
    • Два режима: отображение постов и отображение списка пользователей. Кнопки/контроллеры/другое решение для переключения между ними.

    Список пользователей
    • Таблица с информацией:
    o Имя
    o Фамилия
    o Email
    • Пагинация:
    o Номера страниц
    o Кнопки "Предыдущая"/"Следующая"
    o Выбор количества элементов на странице (10/25/50)
    • Клик по строке - переход на карточку пользователя

    Список постов
    • Таблица
    o ID
    o Заголовок
    • Аналогичная пагинация
    • Клик по строке - переход на карточку поста

    Карточка пользователя/поста
    • Для поста отображаются все комментарии
    • Возможность возврата к списку
    • Интерфейс на усмотрение разработчика
